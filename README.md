# 옥외광고 신고초안

길에서 본 불법 옥외광고물을, 안전신문고에 붙여 넣을 글로 정리하는 웹앱입니다.

## 사용 방법

1. 브라우저에서 이 폴더를 엽니다.

   ```bash
   npm start
   ```

   연 뒤 <http://localhost:4173> 으로 들어갑니다.

2. 광고물 종류, 위치, 현장에서 본 점을 입력합니다.
3. 오른쪽 초안을 복사합니다. 휴대폰에서는 아래 복사 버튼을 누릅니다.
4. [안전신문고](https://www.safetyreport.go.kr) 앱 또는 포털에서 **생활불편신고 → 불법광고물**을 고르고, 위치와 사진과 함께 붙여 넣습니다.

안전신문고 본문은 900자, 사진·동영상은 4개까지입니다. 900자가 넘으면 추가 설명을 줄이고, 전체 글은 **구청 민원** 탭에 남습니다.

이 앱은 신고를 대신 접수하지 않습니다. 적법 여부는 관할 시·군·구가 판단합니다.

## 확인
